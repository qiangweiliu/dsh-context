# /ctx 面板视觉优化（oil-ui 设计稿 v2）

采集日期：2026-10-19 · 插件版本：0.17.0

## 用户任务与主动作

面向「正在用 DSH 干活、想确认这轮对话还有多少上下文余量」的人。首屏要回答的顺序是：
**还剩多少 → 都用在哪了 → 最近几轮趋势 → 想回到哪个会话**。主动作是「看当前会话水位」，不是「浏览统计」。

## 设计北极星

**一个水位表，不是一堆卡片。**

同类工具（Vercel/Linear 的用量页、DSH 自带 ContextMeter）都把"当前用量/上限"当首屏主角，统计降为次级。
本稿沿用 DSH 宿主的语义变量与既有卡片语法，只重排层级、不换皮：

- **一个主角**：上下文水位（环形 + 水位条 + 阈值刻度），放最前。
- **一条统计带**：7 个 KPI 从 7 张独立卡片收成一条分隔带（`bg-layer-1` 容器 + 发丝分隔线），字号从 19px 降到 15.5px，让位给主角。
- **两张图**：每日 tokens 与活跃度按 2:1 分栏且各自贴内容高度，不再等宽等高。
- **会话列表**：去掉卡片底色与下划线链接，靠发丝边框分组，噪声最低。
- **阈值**：从一排 chip 变成水位条上的两条刻度线（警告/超限），文字压成一行。

## 关键改动

| 位置 | 之前 | 之后 |
| --- | --- | --- |
| 页面顺序 | KPI 带 → 图 → 上下文卡 → 会话 | 上下文（hero）→ KPI 带 → 图 → 会话 |
| 上下文卡 | 104px 环 + 4 个底纹方块 + 水位条 + 图例 + 4 个阈值 chip + 提示 | 84px 环 + 无框统计格 + 水位条（带阈值刻度）+ 一行阈值 + 图例 + 提示 |
| KPI | 7 张卡片，值 19px | 一条分隔带，值 15.5px |
| 活跃度热力格 | `auto-fit` 拉伸，少数据时变成一块巨方块 | 固定 20px 方块 + 「少→多」图例 |
| 每日 tokens | 柱宽上限 34px，高度 92px | 柱宽上限 26px，高度 96px |
| 会话卡 | 底色 `bg-layer-2` + 下划线「打开会话↗」 | 透明底 + 发丝边框，动作去掉下划线 |
| 区间选择 | 选中项白底实心，抢走视觉焦点 | 选中项低对比底色 |

数字统一 `tabular-nums`；页面纵向节奏统一 16px；卡片内边距统一 14/16。

## 状态覆盖

- 加载：骨架屏保留（未改）。
- 错误：错误卡 + 重试保留（未改）。
- 空态：会话搜索无结果、无 analytics 时的横幅保留（未改）。
- 窄屏：hero 的统计格 `flex: 1 1 420px`，环与统计格换行；KPI 带 `auto-fit minmax(112px)` 换行；图表 2:1 在窄屏堆叠。

## 动效

沿用既有的水位条 `width .7s cubic-bezier(.22,.61,.36,1)` 与环形 `stroke-dasharray .6s`，未新增动效（工具面板不做入场动画）。

## 宿主复核（WSL，2026-10-19）

在 WSL 的 `web` profile（`~/dsh-plugins/ctx-mon-and-con`，3080 端口实例）上同步源码后实测：

| 检查 | 结果 |
| --- | --- |
| 环形图尺寸 | 84×84（旧 104） |
| KPI | 单容器 7 格，容器底色为 `bg-layer-1`，格间 0.5px 分隔线 |
| 热力图 | 格子固定 20px，「少 / 多」图例在 |
| 会话卡 | 底色透明（不再是一块块浅色磁贴） |
| 会话动作 | `text-decoration: none` |
| 横向溢出 | `scrollWidth == clientWidth == 1400`，无控制台报错 |

**宿主上发现并修掉的两个问题**（设计稿没暴露出来的）：

1. `CtxPanel` 里概览页的推送顺序仍是 KPI → 图 → 上下文，hero 并没有真的前置；已改成 上下文 → KPI → 图。
2. 0% 用量时水位条左侧露出 2px 残留色块（`min-width: 2px` 让空条也有一截颜色）；已在 `MeterBar` 与 `SegmentedBar` 里改成 0% 不画。
3. 中文下「上下文」标签与卡片标题、与「剩余」撞词，改为新键 `budgetLimit`（预算上限 / Budget cap）。
